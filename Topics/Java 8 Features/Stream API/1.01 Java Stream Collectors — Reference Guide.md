# Java Stream Collectors — Reference Guide

A quick-reference guide to the most commonly used `java.util.stream.Collectors` methods, with syntax, examples, and results. All examples assume a stream of `Employee` objects with `getName()`, `getDepartment()`, `getId()`, `getAge()`, and `getSalary()` accessors. All examples use **lambda expressions** rather than method references.

## 1. Collectors.toList()

**Purpose:** Collect stream elements into a `List`.

```java
Collectors.toList()
```

**Example**
```java
List<String> names = employees.stream()
        .map(emp -> emp.getName())
        .collect(Collectors.toList());
```

**Result**
```
[Abhilash, Rahul, Priya, Sneha]
```

---

## 2. Collectors.toSet()

**Purpose:** Collect stream elements into a `Set`. Duplicates are automatically removed.

```java
Collectors.toSet()
```

**Example**
```java
Set<String> departments = employees.stream()
        .map(emp -> emp.getDepartment())
        .collect(Collectors.toSet());
```

**Result**
```
[IT, HR, Finance]
```

---

## 3. Collectors.toMap()

**Purpose:** Convert stream elements into a `Map`.

```java
Collectors.toMap(
    keyMapper,
    valueMapper
)
```

**Example**
```java
Map<Integer, String> result = employees.stream()
        .collect(Collectors.toMap(
                emp -> emp.getId(),
                emp -> emp.getName()
        ));
```

**Result**
```
1 → Abhilash
2 → Rahul
3 → Priya
```

> ⚠️ **Important:** Duplicate keys cause an `IllegalStateException` unless you provide a merge function.

**Syntax with merge function**
```java
Collectors.toMap(
    keyMapper,
    valueMapper,
    mergeFunction
)
```

**Example**
```java
Map<String, String> result = employees.stream()
        .collect(Collectors.toMap(
                emp -> emp.getDepartment(),
                emp -> emp.getName(),
                (existing, replacement) -> existing
        ));
```

## 4. Collectors.groupingBy()

**Purpose:** Group elements based on a property.

```java
Collectors.groupingBy(
    classifier
)
```

**Example**
```java
Map<String, List<Employee>> result = employees.stream()
        .collect(Collectors.groupingBy(
                emp -> emp.getDepartment()
        ));
```

**Result**
```
IT → [Employee1, Employee2, Employee3]
HR → [Employee4, Employee5]
```

## 5. groupingBy() with a downstream collector

**Purpose:** Group elements and perform an additional operation on each group.

```java
Collectors.groupingBy(
    classifier,
    downstreamCollector
)
```

**Example — count employees in each department**
```java
Map<String, Long> result = employees.stream()
        .collect(Collectors.groupingBy(
                emp -> emp.getDepartment(),
                Collectors.counting()
        ));
```

**Result**
```
IT → 3
HR → 3
Finance → 2
```

## 6. Collectors.mapping()

**Purpose:** Transform elements inside a collector. Commonly paired with `groupingBy()`.

```java
Collectors.mapping(
    mapper,
    downstreamCollector
)
```

**Example — group employees by department, collect only names**
```java
Map<String, List<String>> result = employees.stream()
        .collect(Collectors.groupingBy(
                emp -> emp.getDepartment(),
                Collectors.mapping(
                        emp -> emp.getName(),
                        Collectors.toList()
                )
        ));
```

**Mental model**
```
Employee → (emp -> emp.getName()) → String → toList()
```

## 12. Collectors.maxBy()

**Purpose:** Find the maximum element.

```java
Collectors.maxBy(
    comparator
)
```

**Example — employee with the highest salary**
```java
Optional<Employee> highestPaidEmployee = employees.stream()
        .collect(Collectors.maxBy(
                (emp1, emp2) -> Double.compare(emp1.getSalary(), emp2.getSalary())
        ));
```

**Grouped example**
```java
Map<String, Optional<Employee>> result = employees.stream()
        .collect(Collectors.groupingBy(
                emp -> emp.getDepartment(),
                Collectors.maxBy(
                        (emp1, emp2) -> Double.compare(emp1.getSalary(), emp2.getSalary())
                )
        ));
```

## 14. Collectors.summarizingDouble()

**Access values**
```java

statistics.getSum();
statistics.getMin();
```

## 15. Collectors.partitioningBy()

**Purpose:** Divide elements into exactly two groups based on a condition (`true`/`false`).

```java
Collectors.partitioningBy(
    predicate
)
```

**Example — separate employees by age**
```java
Map<Boolean, List<Employee>> result = employees.stream()
        .collect(Collectors.partitioningBy(
                emp -> emp.getAge() >= 25
        ));
```

**Result**
```
true  → Employees age >= 25
false → Employees age < 25
```

## 16. Collectors.joining()

**Purpose:** Join `String` elements.

**Basic**
```java
Collectors.joining()
```
```java
String result = employees.stream()
        .map(emp -> emp.getName())
        .collect(Collectors.joining());
```
Result: `AbhilashRahulPriya`

**With delimiter**
```java
Collectors.joining(delimiter)
```
```java
String result = employees.stream()
        .map(emp -> emp.getName())
        .collect(Collectors.joining(", "));
```
Result: `Abhilash, Rahul, Priya`

**With delimiter, prefix, and suffix**
```java
Collectors.joining(delimiter, prefix, suffix)
```
```java
String result = employees.stream()
        .map(emp -> emp.getName())
        .collect(Collectors.joining(", ", "[", "]"));
```
Result: `[Abhilash, Rahul, Priya]`

## 17. Collectors.collectingAndThen()

**Purpose:** First collect data, then perform another operation on the collected result.

```java
Collectors.collectingAndThen(
    collector,
    finisher
)
```

**Example — create an unmodifiable list**
```java
List<String> names = employees.stream()
        .map(emp -> emp.getName())
        .collect(Collectors.collectingAndThen(
                Collectors.toList(),
                list -> Collections.unmodifiableList(list)
        ));
```

**Mental model**
```
Stream → Collector (does the main collection) → Finisher (final operation) → Result
```

## The Most Important Pattern to Remember

Almost everything above boils down to one formula:

```java
Collectors.groupingBy(
    KEY,
    OPERATION_ON_EACH_GROUP
)
```

`groupingBy()` decides **how to create the groups**; the downstream collector decides **what operation happens inside each group**.

| Goal | Code |
|---|---|
| Group by department | `Collectors.groupingBy(emp -> emp.getDepartment())` |
| Count employees per group | `Collectors.groupingBy(emp -> emp.getDepartment(), Collectors.counting())` |
| Get employee names per group | `Collectors.groupingBy(emp -> emp.getDepartment(), Collectors.mapping(emp -> emp.getName(), Collectors.toList()))` |
| Calculate average salary per group | `Collectors.groupingBy(emp -> emp.getDepartment(), Collectors.averagingDouble(emp -> emp.getSalary()))` |
| Find highest-paid employee per group | `Collectors.groupingBy(emp -> emp.getDepartment(), Collectors.maxBy((e1, e2) -> Double.compare(e1.getSalary(), e2.getSalary())))` |

**The mental formula:**
```
groupingBy(KEY, DOWNSTREAM_COLLECTOR)
```

This is the single most important concept for solving Java Stream Collectors problems.
